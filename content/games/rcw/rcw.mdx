Every round a **word** will be displayed in a **random color**. Use your left and right arrow keys to decide if it's correct or not. Tap the right arrow key if the color matches the word, and the left arrow key if not.

Sometimes, the round will be reversed. In this case, switch the arrow keys you use to select between correct and incorrect matches.

The faster you answer each round, the more points you'll get. There's no ending, rounds are 3 seconds long, good luck.

If you're curious about how I made this game, I also wrote <a href="/projects/rcw" class="link-primary">a write-up</a> about the development process.
